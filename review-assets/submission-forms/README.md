# Submission forms — before and after

Before: public main at `ba21271970bcf4ca3d7399d0855a0dc8253a8c12`. After: the workload and environment form rework at `e87ff32790e484930a11e12ef353fa75798f594d`.

Matching synthetic data, roles, stages and viewport sizes. Captured from the actual React/Carbon views with mocked IPC/API responses. No contract actions were sent to the central backend. Dark captures use Carbon g100; the compact window is 1024px wide, matching Electron’s minimum window width.

These review images live on a separate documentation branch and are excluded from the implementation PR.
